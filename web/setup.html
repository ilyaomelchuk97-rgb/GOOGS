Перенос данных в Forma

Здесь вы один раз перетащите личную ZIP-копию базы с вашего компьютера. Это не архив кода для GitHub. Загрузка возможна только пока облачная база пуста.

Важно: до отправки придумайте новый длинный пароль администратора. Он заменит старый пароль admin ещё до первого публичного входа. Архив на диск Render не записывается.
После успешного переноса удалите INITIAL_IMPORT_TOKEN из Render, войдите в сайт под показанным логином и новым паролем, скачайте свежую резервную копию. Не отправляйте ZIP и ключи в GitHub или чат.
