# Подключение LiveKit Cloud к Forma — пошаговая инструкция

**Для кода Forma `20261022-48`.** Настройка ключей не обновляет код сайта: сначала опубликуйте свежую версию Forma из `forma-code-for-github.zip`, затем добавьте ключи в Render. Видеосвязь P2P проверена в двух настоящих браузерах Chromium с тестовыми камерами; реальное облачное подключение LiveKit без вашего проекта и ключей здесь не испытывалось.

## Бесплатно ли это?

**Да, у LiveKit Cloud есть бесплатный тариф Build — $0/месяц, без обязательной банковской карты**, но это не безлимитное видео. По опубликованным условиям для WebRTC на Build включены **5 000 минут подключения участников за календарный месяц**, **50 ГБ исходящего из LiveKit трафика** и до **100 одновременно подключённых участников во всех комнатах проекта**. На бесплатном тарифе превышение включённого ресурса является *жёстким лимитом*: новые операции могут не пройти, а не автоматически превратиться в платный счёт. Квоты общие для бесплатных проектов одного владельца; объём обновляется в начале месяца. Всегда сверяйте актуальные цифры в **LiveKit Cloud → Settings → Project** и на странице тарифов — условия могут измениться. Источники: [1](https://livekit.com/pricing), [1](https://docs.livekit.io/deploy/admin/quotas-and-limits/).

**Минуты считаются по людям, не по собраниям.** Если 15 человек сидят один час, это примерно **15 × 60 = 900 участнико-минут**. Поэтому 5 000 минут — теоретически около **5 ч 33 мин** таких собраний в месяц, *если раньше не закончится 50 ГБ трафика*. У видеосвязи с несколькими камерами расход трафика зависит от качества и подписок; гарантировать конкретное число бесплатных собраний нельзя. За отдельный хостинг Render тоже могут взиматься расходы по его тарифу — бесплатная квота LiveKit не оплачивает Render.

Forma **не использует LiveKit Agents, AI-модели, транскрипцию и запись**, поэтому тарифные «минуты агента» и цены ИИ-моделей не нужны для обычных видеозвонков Forma. Бесплатен и браузерный клиентский SDK (Apache-2.0, лицензия включена в архив); лимиты выше относятся именно к облачному переносу медиа.

## Что понадобится

- Доступ к панели **Render**, где запущен именно веб‑сервис Forma.
- Аккаунт на [cloud.livekit.io](https://cloud.livekit.io/) и отдельный проект для Forma. Проект в LiveKit Cloud создаётся через панель управления. [1](https://docs.livekit.io/reference/developer-tools/livekit-cli/projects/)
- Опубликованная версия Forma `20261022-48`: проверьте адрес `https://АДРЕС-ВАШЕЙ-FORMA/health` — в JSON должно быть `"build":"20261022-48"`. Если там старый номер, **сначала обновите код и схему** по `CALLS_DEPLOY.md`; одни ключи звонки в старой версии не добавят.
- Два разных аккаунта сотрудников Forma и два браузера/устройства для окончательной проверки. У обоих должен быть доступ к одной беседе. Сайт должен открываться через HTTPS, иначе браузер может запретить камеру и демонстрацию экрана.

## Шаг 1. Создайте проект LiveKit

1. Перейдите на **https://cloud.livekit.io/**, зарегистрируйтесь или войдите.
2. Создайте новый проект (*Create project* / *New project*). Например, назовите его `Forma`. Для проверки можно использовать отдельный тестовый проект, чтобы не смешивать его статистику с другими приложениями.
3. Внутри проекта откройте **Settings → Project** (или сведения проекта) и скопируйте **Project URL**. Он должен начинаться с `wss://`, например `wss://forma-example.livekit.cloud`. Это адрес WebSocket **вашего проекта**, не `https://cloud.livekit.io/` и не адрес сайта Forma. Местоположение поля может меняться с обновлением панели LiveKit. [2](https://docs.livekit.io/reference/developer-tools/livekit-cli/#app-templates)

## Шаг 2. Создайте ключ API

1. В том **же проекте** откройте **Settings → Keys** / **API keys** (названия вкладок могут немного отличаться).
2. Выберите **Create key** и создайте ключ специально для Forma. Скопируйте оба значения: **API Key** и **API Secret**. Если секрет показывается однократно — сохраните его во временном защищённом месте, пока вводите в Render. Не путайте ключ одного проекта с URL другого. Инструкция по расположению ключей: [2](https://community.livekit.io/t/where-to-find-the-livekit-api-key-and-secret/92).
3. **Не присылайте мне секрет, не вставляйте его в чат, GitHub, `web/main.js`, `web/calls.js` или публичный `.env`.** Секрет нужен только серверу Forma на Render: он подписывает ограниченные токены подключения для сотрудников. [3](https://docs.livekit.io/deploy/agents/secrets/)

## Шаг 3. Добавьте переменные на Render

1. Войдите в **dashboard.render.com → ваш Web Service Forma → Environment → Environment Variables → Add Environment Variable**.
2. Добавьте **три отдельных** параметра (без кавычек и пробелов вокруг значения):

   | Key | Value |
   | --- | --- |
   | `LIVEKIT_URL` | `wss://АДРЕС-ВАШЕГО-ПРОЕКТА.livekit.cloud` |
   | `LIVEKIT_API_KEY` | API Key из **этого же проекта** |
   | `LIVEKIT_API_SECRET` | API Secret из **этого же проекта** |

3. Выберите **Save and deploy** или **Save, rebuild, and deploy**. **Save only** отложит применение переменных до следующего развертывания. Дождитесь успешного завершения Deploy. Это штатный путь добавления переменных Render: [1](https://render.com/docs/configure-environment-variables).
4. Не изменяйте остальные существующие переменные Forma (`DATABASE_BACKEND`, D1, резервные копии и т. п.). **Не загружайте рабочую базу, архив ZIP с данными или секреты в репозиторий.**

> Не используйте `LIVEKIT_URL=https://...`: в текущей реализации Forma облачный режим включается только при URL `wss://...` и наличии **всех трёх** параметров. Секрет не должен отображаться на странице чата: браузер получает только временный токен для конкретного звонка.

## Шаг 4. Проверьте связь

1. На сайте Forma откройте `/health` и убедитесь в версии `20261022-48`.
2. Зайдите **двумя разными сотрудниками** в разных браузерах или устройствах на опубликованный HTTPS-сайт.
3. Откройте общую или личную беседу. В первом браузере нажмите **Видеозвонок**, подтвердите вход и разрешите камеру/микрофон. Во втором дождитесь всплывающего приглашения и нажмите **Присоединиться**. В панели звонка должно отображаться **«LiveKit · максимум 15»**, а оба участника должны видеть/слышать друг друга.
4. Во время теста нажмите **Показать экран / окно / вкладку** и выберите объект в стандартном диалоге браузера. Выйдите сначала на одном, затем на другом устройстве: после выхода последнего звонок должен завершиться.
5. Проверьте использование и оставшуюся квоту в панели LiveKit Cloud. Для регулярных 15‑местных встреч учитывайте **и участнико‑минуты, и 50 ГБ исходящего трафика**.

## Если не заработало

| Признак | Что проверить |
| --- | --- |
| Панель показывает **P2P**, а не LiveKit | Код версии `20261022-48` действительно опубликован? Все три переменные записаны **на том Render Web Service**, который обслуживает Forma? `LIVEKIT_URL` начинается с `wss://`? После изменения переменных был Deploy? |
| Ошибка токена или 401 при соединении с LiveKit | URL, Key и Secret взяты из **одного** LiveKit‑проекта? Не добавлены кавычки/пробелы? При смене или компрометации ключа замените значения в Render и сделайте Deploy. |
| Вход разрешён, но нет камеры/экрана | Разрешите доступ в адресной строке браузера, проверьте настройки ОС и работайте по HTTPS. При демонстрации выбор экрана/окна/вкладки делается в окне браузера, сайт сам выбирать приложение не может. |
| Первый участник подключился, второй не видит приглашение | У второго открыта Forma и действующая сессия входа? В закрытой группе он числится участником? Подождите несколько секунд, затем обновите страницу. |
| В предпросмотре собеседник видит только себя, камер не видно | До сборки `20261022-48` сигналы P2P могли потеряться, если пришли раньше списка участников. Обновите код и повторите звонок. Встроенный предпросмотр также может запретить доступ к камере: откройте **адрес живого предпросмотра в новой вкладке HTTPS**, разрешите камеру и микрофон и перезайдите обоими участниками. В P2P без TURN некоторые сети всё равно не соединятся. |
| Раньше работало, потом новые соединения перестали открываться | Проверьте **Settings → Project / Usage** в LiveKit: возможно, закончилась бесплатная квота участнико‑минут или трафика. На Build это жёсткий лимит, не бесконечное бесплатное использование. [1](https://docs.livekit.io/deploy/admin/quotas-and-limits/) |
| Облако временно недоступно | Если LiveKit не установил соединение и другие участники ещё не вошли, Forma предложит явный переход на P2P. Резервный режим — **до 4 пользователей, без TURN**; в некоторых сетях он не соединяется. |

**Важно:** при исключении человека из закрытой группы сервер старается отключить подключённого участника через LiveKit RoomService. Однако ранее выданный токен пользователя, который уже вышел из звонка, отдельно не отслеживается и теоретически может действовать до истечения 10 минут. Политика и дополнительные ограничения описаны в `CALLS_DEPLOY.md`.
