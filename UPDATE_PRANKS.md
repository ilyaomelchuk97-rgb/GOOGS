# Как обновить уже работающий сайт: меню, шрифт и новые приколы

**Не создавайте новый Render-сервис и не переносите базу заново.** Cloudflare Worker, D1, ключи и Google-копии менять не нужно. Изменения касаются только кода Python, интерфейса и картинок кота. Если новые приколы уже установлены и нужно обновить **только** боковое меню, шрифт и поля по краям, хватит трёх файлов в папке `web`: `main.js`, `styles.css`, `index.html` (шаги 1, 3, 4 ниже).

1. Скачайте свежий `forma-code-for-github.zip` и **распакуйте** его. Архив кода не содержит базу и пароли.
2. В своём репозитории GitHub откройте **корень** (там, где `app.py`) → **Add file → Upload files**. Перетащите **`app.py`** из распакованной папки; GitHub должен показать обновление файла с тем же именем. Нажмите **Commit changes**.
3. В GitHub откройте папку **`web`** → **Add file → Upload files**. Перетащите из локальной папки `web` **ровно пять файлов**: `main.js`, `styles.css`, `index.html`, `courier-cat.png`, `courier-cat-walk.png`. Нажмите **Commit changes**. В результате они должны быть **в папке `web`**, а не в корне GitHub.
4. Подождите, пока Render завершит новый деплой. Откройте свой сайт и обновите страницу (`Ctrl+F5`, на телефоне — заново откройте вкладку). Убедитесь, что слева сверху есть кнопка **☰**, а меню изначально скрыто. Откройте его, выберите раздел и убедитесь, что меню закрылось. Затем администратор → **Прикол** → попробуйте «Тест у себя» на карточках кота, достижения и парада. Для отправки выберите сотрудника, который сейчас в сети.
5. Если кота или смены лап нет, проверьте в GitHub пути **`web/courier-cat.png`** и **`web/courier-cat-walk.png`**; если карточек нет — **`web/main.js`** и завершение деплоя Render. Никаких ZIP с рабочими данными в GitHub не загружайте.

Кот нарисован в `web/courier-cat.png` (прозрачный фон); четыре позы в `web/courier-cat-walk.png` меняют положение лап примерно восемь раз в секунду, пока он перемещается средствами CSS/JavaScript. Новые эффекты хранятся в прежней таблице событий без изменений структуры базы. Они доступны только администратору, короткие, не мешают вводить данные и не требуют дополнительного расхода D1 при показе анимации.
