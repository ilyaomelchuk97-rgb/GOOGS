# Сотрудник исчезает после выдачи прав администратора — как поставить исправление

**Проверка 6 октября 2026 года:** `https://googs-seogs.onrender.com/` отдавал `main.js?v=20261006-23` — старую версию интерфейса, в которой нет исправления личного листа администратора-сотрудника. Даже если файлы уже были загружены куда-то на GitHub, этот Render-сервис их ещё не показывал.

## Сделайте по шагам, без командной строки

1. В действующем сайте откройте **«Резервные копии» → скачать ZIP** и сохраните личную копию у себя. **Не загружайте этот ZIP на GitHub**.
2. Скачайте обновлённый `forma-code-for-github.zip` и **распакуйте** его на компьютере. Откройте именно репозиторий GitHub, связанный с действующим Render-сервисом `googs-seogs`.
3. В корне репозитория GitHub (где уже лежит `app.py`) нажмите **Add file → Upload files**, выберите новые **`app.py`**, **`backup_tools.py`**, **`d1_store.py`**, подтвердите **Commit changes**. Не кладите файлы в дополнительную вложенную папку.
4. Откройте в репозитории папку **`web`**, нажмите **Add file → Upload files**, выберите новые **`main.js`**, **`index.html`** и **`styles.css`**, подтвердите **Commit changes**. В GitHub должны получиться адреса **`web/main.js`**, **`web/index.html`** и **`web/styles.css`**, а не `forma-code-for-github/web/...` внутри репозитория.
4а. В GitHub откройте папку **`cloudflare`** и замените **`schema.sql`** на одноимённый файл из архива — он нужен для резервной копии новых сообщений. Код самого Worker менять не требуется.
5. Откройте Render → ваш сайт `googs-seogs` → **Events / Deploys**. Дождитесь успешного деплоя после последних двух сохранений GitHub. Если он не начался, нажмите **Manual Deploy → Deploy latest commit**. Проверьте, что выбран нужный репозиторий и ветка.
6. Проверьте **`https://googs-seogs.onrender.com/health`**: после настоящего обновления там будет **`"build":"20261007-31"`**. Откройте сайт заново, обновите страницу принудительно (`Ctrl+F5`). В исходном коде главной страницы должна быть строка `main.js?v=20261007-31`.
7. Проверьте повышенного сотрудника: его данные и табель не удалены, он остаётся в графиках и списке «Сотрудники» с правами администратора. Но в сводном отчёте, скачиваемом Excel и выборе сотрудника раздела «Мои работы» его нет, пока у него роль администратора. После возврата роли «сотрудник» записи снова появляются в отчёте и его можно выбрать в «Моих работах».

Никаких изменений Cloudflare Worker, повторной загрузки базы или SQL-команд не требуется. На новом запуске приложение аккуратно возвращает ошибочно скрытых повышенных сотрудников в список работников; созданные ранее работы не удаляются. Если `/health` по-прежнему не показывает нужную сборку, пришлите **адрес репозитория GitHub** и **скриншот последнего деплоя Render** (без паролей и секретов): можно будет определить, куда именно попали файлы.

## Если в Microsoft Edge не двигаются кот, конфетти и парад

Если в Windows выключены **«Эффекты анимации»**, прежний сайт отключал эти эффекты через `prefers-reduced-motion`. В сборке **20261007-31** именно эффекты раздела «Прикол» запускаются и при этой системной настройке. Проверьте версию сайта по `/health` и `main.js?v=20261007-31`, обновите страницу. Пульсации и прочие неигровые эффекты могут по-прежнему учитывать настройки Windows.

## Если нужна выгрузка в форме вкладки «Отчёт» исходного Excel

Замените **`app.py`** в корне правильного репозитория GitHub, дождитесь нового деплоя Render и проверьте `/health`: **`"build":"20261007-31"`**. В разделе «Сводный отчёт» выберите месяц и нажмите «Скачать Excel». Первый лист будет повторять вкладку «Отчёт» файла `source.xlsx`: «По количеству» слева, норма посередине, «По времени» справа, итоги, производительность, отработанные часы и помесячная история внизу. Значения — из данных сайта, а не старые числа файла. Дополнительные листы табеля, записей и комментариев сохранятся. Если другие изменения интерфейса всё ещё не установлены, дополнительно загрузите файлы из папки `web` по шагам выше.
