# Чат в Forma — как включить на работающем сайте

Можно писать **лично любому активному пользователю** (включая администраторов) и в **общий чат команды**. Сообщения хранятся в Cloudflare D1. Страница чата подгружает новые сообщения примерно каждые 3,5 секунды, пока она открыта. Вложения и push-уведомления не добавлены.

## Обновление через браузер, без терминала

1. На действующем сайте под администратором откройте **«Резервные копии» → «Скачать»** и сохраните ZIP у себя. Никогда не загружайте личный ZIP в GitHub.
2. Скачайте `forma-code-for-github.zip` из этого чата и **распакуйте** на компьютере. Откройте ваш репозиторий **https://github.com/ilyaomelchuk97-rgb/GOOGS**, ветка **main**.
3. В **корне** репозитория замените три файла: `app.py`, `backup_tools.py`, `d1_store.py`. Для каждого используйте **Add file → Upload files → Commit changes**. Можно выбрать все три сразу.
4. Зайдите в папку **web** и замените три файла: `index.html`, `main.js`, `styles.css`. Они должны оказаться по адресам `web/index.html`, `web/main.js`, `web/styles.css` — без лишней папки внутри репозитория.
5. Зайдите в папку **cloudflare** и замените `schema.sql` файлом `cloudflare/schema.sql` из архива. **Не меняйте** код Cloudflare Worker, токены, базу данных и файлы личных резервных копий.
6. Откройте Render → сервис `googs-seogs` → **Events / Deploys**. Дождитесь успешного деплоя последнего коммита; если он не начался, нажмите **Manual Deploy → Deploy latest commit**.
7. Откройте https://googs-seogs.onrender.com/health. Для новой версии там должно быть **`"build":"20261007-31"`**. В исходном коде главной страницы проверьте `main.js?v=20261007-31` и `styles.css?v=20261007-31`. Затем обновите сайт (`Ctrl+F5`).
8. Войдите под двумя разными пользователями: в разделе **«Чат»** проверьте личную беседу и **«Общий чат»**. Личную беседу третья учётная запись видеть не должна. Чат автоматически создаёт новую таблицу в D1 при запуске Render; ручные SQL-команды или повторный импорт данных не нужны.

Сообщения включены в резервные копии и считаются изменением для почасовой проверки Google Диска. Старые архивы без чата по-прежнему восстанавливаются, но в них не будет новых сообщений. Учтите действующий предел атомарного восстановления D1 — около **490 КБ** несжатого транспортного пакета: при долгой переписке понадобится отдельный план переноса/архивации, не удаляющий сообщения незаметно.
